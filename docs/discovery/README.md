# Discovery

Pesquisa, briefings, análise competitiva e brainstorming. O que se descobriu
antes de decidir o que construir.

Escreve aqui: `/anvil-grill`, `/anvil-research`, `/anvil-distill`. O grill grava,
a cada bloco de perguntas, as decisões em `grill-<assunto>.md`; num branch de
spec, o registro vai na pasta `discovery/` da spec.
