A camada ganha a rule `anvil-harness`, curta e sempre aplicada, que traduz o vocabulário do Claude Code para as primitivas do omp, e a skill `anvil-omp`, com trava de invocação, que explica a camada.

**Blocked by:** 03

**Status:** resolved
